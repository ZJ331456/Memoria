# Chat：独立对话界面

[前端构建](../README.md) · [项目首页](../../README.md)

生产入口为根地址 `/`。独立Vue入口和CSS，包含个人会话列表/搜索/分页、新对话、用户与助手消息、加载更早记录、输入框、Enter发送/Shift+Enter换行、流式状态/回复与停止按钮。适配窄屏抽屉（Esc关闭、打开自动聚焦搜索），提供通往Studio的链接，不承载后台导航、统计和审核表单。键盘快捷键：Ctrl/Cmd+K聚焦会话搜索、Alt+N新对话。会话列表悬停支持重命名（行内编辑）与删除（二次确认）；仅本人会话可管理，导入语料只读。输入接近上限时显示字符计数。

新对话按钮仅清空界面；首次发送才创建当前账号会话并调用现有Agent SSE接口。失败/停止后重新读取实际保存记录，断流不自动重试，避免重复写入或计费。模型严格Reader的校验策略保持，界面不承诺逐Token即时到达。助手保存消息与流式回复使用共享安全Markdown，用户文本原样显示；用户在右、助手在左。支持复制原文、助手原文/阅读切换、滚动跟随和回到最新；不支持附件/语音，渲染不执行HTML或代码，不自动加载远程图片。

Chat只列原生聊天，公开导入历史在Studio查看，不混为本人对话。未登录先显示共享登录/注册组件；跨标签退出与换号清空消息、输入、列表和在途流。不会填充模拟聊天，也不写默认账号密码。

工程验证使用隔离替身，生产资料只读核对，不将界面接通算作长期记忆效果或新模型成绩。

登录后在左下角用户名账号菜单选择“飞书连接”可核对机器人长连接、生成本账号一次性码并明确解绑。[配置与手机步骤](../../docs/implemented/飞书机器人对话接入.md)；应用配置由本机管理员维护，页面不显示应用ID或Secret。本人手机绑定后的真实文字对话会出现在同账号聊天列表。

同一账号菜单的“修改密码”使用shared/PasswordPanel与正式账号接口，验证旧密码后撤销本账号全部旧登录；成功提示重新登录，资料保留。[操作与边界](../../docs/implemented/用户登录与数据隔离.md#当前账号自助修改密码2026-10-15)。
