# Chat：独立对话界面

[前端构建](../README.md) · [项目首页](../../README.md)

生产入口为根地址 `/`。独立Vue入口和CSS，包含个人会话列表/搜索/分页、新对话、用户与助手消息、加载更早记录、输入框、Enter发送/Shift+Enter换行、流式状态/回复与停止按钮。适配窄屏抽屉，提供通往Studio的链接，不承载后台导航、统计和审核表单。

新对话按钮仅清空界面；首次发送才创建当前账号会话并调用现有Agent SSE接口。失败/停止后重新读取实际保存记录，断流不自动重试，避免重复写入或计费。模型严格Reader的校验策略保持，界面不承诺逐Token即时到达。消息按文本安全渲染，保留原内容与引用标记，暂不支持Markdown富文本/附件/语音。

Chat只列原生聊天，公开导入历史在Studio查看，不混为本人对话。未登录先显示共享登录/注册组件；跨标签退出与换号清空消息、输入、列表和在途流。不会填充模拟聊天，也不写默认账号密码。

工程验证使用隔离替身，生产资料只读核对，不将界面接通算作长期记忆效果或新模型成绩。
