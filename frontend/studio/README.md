# Memory Studio：数据与记忆管理后台

[前端目录/构建](../README.md) · [行为与验证](../../docs/implemented/MemoryStudio与统一记忆访问.md) · [API](../../memoria/api/README.md)

Vue 3 + TypeScript + Element Plus，入口 `/studio/`。保留数据总览、完整历史全文搜索/来源/分页/命中定位、普通记忆库、候选审核、结构化Claim审核、双时间、检索实验室、只读评测运行及超管账号元数据。页面不提供聊天发送/新建；需要交流时通过“返回Chat”到根地址。

依赖、锁文件、Vite配置和测试统一在上级frontend；不要在本目录npm install。构建/开发命令见[上级说明](../README.md)，两个入口共用Cookie、账号生命周期和请求归属保护。

src/App.vue负责后台模块，src/components负责历史/来源、总览、普通记忆、待审候选和账号元数据。共享API/登录/文本工具在../shared，后台专有全局CSS仅从Studio入口加载。

历史按原文保存，中文逐字空格仅作可切换阅读/检索投影。公开语料/非本人原话不能提出个人Claim；审核始终明确执行。原50段/206条来源资料仍归原账号实验空间，新账号保持真实空状态；没有模拟数据或按用户名写特例。超管元数据权限不自动取得其他用户记忆。

当前验证和限制见[前端实现报告](../../docs/implemented/Chat与Studio前端架构.md)。界面和工程通过不作为研究成绩，长期本人资料、语义支持与商用恢复验收仍待完成。

右上角“连接飞书”复用shared账号绑定弹窗，当前用户自行连接自己的飞书身份；不展示私人应用凭据或切换他人数据。[机器人接入说明](../../docs/implemented/飞书机器人对话接入.md)。
