# Memory Studio：数据与记忆管理后台

“资料与经验”（#library）支持笔记、文档和任务结果的独立保存/阅读/修订/检索、验收反馈、提炼及撤回；数据来自当前账号/library接口，不造聊天记录。保存/检索不调用模型，明确提炼才产生模型调用。

[前端目录/构建](../README.md) · [行为与验证](../../docs/implemented/MemoryStudio与统一记忆访问.md) · [API](../../memoria/api/README.md)

Vue 3 + TypeScript + Element Plus，入口 `/studio/`。保留数据总览、完整历史全文搜索/来源/分页/命中定位、普通记忆库、候选审核、结构化Claim审核、双时间、检索实验室、只读评测运行及超管账号元数据。页面不提供聊天发送/新建；需要交流时通过“返回Chat”到根地址。

依赖、锁文件、Vite配置和测试统一在上级frontend；不要在本目录npm install。构建/开发命令见[上级说明](../README.md)，两个入口共用Cookie、账号生命周期和请求归属保护。

src/App.vue负责后台模块，src/components负责历史/来源、总览、普通记忆、待审候选和账号元数据。共享API/登录/文本工具在../shared，后台专有全局CSS仅从Studio入口加载。

历史按原文保存，中文逐字空格仅作可切换阅读/检索投影。公开语料/非本人原话不能提出个人Claim；默认LLM主审低风险候选，敏感/冲突/不确定项转人工辅助。原50段/206条来源资料仍归原账号实验空间，新账号保持真实空状态；没有模拟数据或按用户名写特例。超管元数据权限不自动取得其他用户记忆。

当前验证和限制见[前端实现报告](../../docs/implemented/Chat与Studio前端架构.md)。界面和工程通过不作为研究成绩，长期本人资料、语义支持与商用恢复验收仍待完成。

右上角用户名账号菜单的“飞书连接”复用shared账号绑定弹窗，当前用户自行连接自己的飞书身份；不展示私人应用凭据或切换他人数据。[机器人接入说明](../../docs/implemented/飞书机器人对话接入.md)。

同一账号菜单提供“修改密码”、切换账号、退出登录；超管另有账号管理入口。改密需验证旧密码；成功后重新登录且资料保留。助手历史支持Markdown/文本模式切换，搜索时回到文字高亮，来源检查仍展示原文。与Chat复用shared组件和安全边界。

## 日常管理与高级诊断

“记忆处理与服务”新增[观察与跨会话模式](../../docs/implemented/记忆形成巩固与演化.md)：查看观察、明确自述路径、模式的审核/演化状态和来源。每5秒只读刷新，不自动批量重提取旧历史；Chat/历史同时区分等待证据积累与已批准事实。

主导航为总览、历史、长期记忆、候选审核、记忆处理与服务；结构化Claim、双时间、检索实验室和评测账本位于可折叠的高级区域。总览功能地图说明用途、资料前提及尚无专用界面的机制。

历史中可从有效本人原话发起LLM提取与审核，低风险自动入库；仍可手动提出候选；长期记忆支持纠正、可读版本/旧来源回查与Markdown导出。处理页区分明确0候选和旧任务未记录，不把completed当作已入库；失败重试需确认并可能产生费用。浏览状态、提出手动候选和读取评测账本不调用模型。

页头统一展示当前页面标题/用途和账号操作，总览不重复显示欢迎区；浏览历史按钮位于同一操作区。桌面紧凑对齐，窄屏换行，长用户名与弹出层不越出视口。[布局与验收](../../docs/implemented/Chat与Studio前端架构.md#studio紧凑页头2026-10-16)。

候选页默认显示全部决定，含自动入库/拒绝及需人工辅助原因；再次点击LLM审核可能计费。改写型Claim可进行语义核验，仍不能覆盖来源、主体、条件、时间和冲突保护。[当前规则](../../docs/implemented/LLM自动审核与人工辅助.md)。
