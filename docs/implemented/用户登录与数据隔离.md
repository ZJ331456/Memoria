## 注册与登录

| 请求 | 行为 |
| --- | --- |
| `POST /api/auth/register` | JSON 为 username、password；成功 201，重复或预留名 409 |
| `POST /api/auth/login` | 返回 user、access_token、token_type、expires_in；同时设置登录 Cookie |
| `GET /api/auth/me` | 返回当前账号的服务端 ID 和 username |
| `POST /api/auth/logout` | 撤销当前令牌并删除 Cookie，204 |

用户名规范化为小写：3–32 位英文、数字、下划线，字母开头。密码 12–128 字符，数据库使用随机盐与 scrypt（N=2^17、r=8、p=1），不保存明文。此配置参考 [OWASP 密码存储指南](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。

登录令牌为 256 bit 随机值，有效期 12 小时；只保存 SHA256，退出后后续请求立即失效。本机重设密码撤销该账号全部会话。Cookie 为 HttpOnly / SameSite=Strict，HTTPS 下为 Secure；也可使用 `Authorization: Bearer <access_token>`。Authorization 出现时不回退到 Cookie，错误令牌不能借 Cookie 绕过验证。令牌是凭据，登录返回内容不要粘贴到聊天或提交。

登录/注册按账号每 10 分钟 10 次、来源 IP 每 10 分钟 30 次限流；密码计算最多并发 2 个。所有请求限制实际流式请求体大小，不能用 chunked 绕过 Content-Length。写请求检查 Origin 和 Sec-Fetch-Site；远程 API 访问必须 HTTPS，本机回环可 HTTP。默认只监听 127.0.0.1；远程部署需正确配置 TLS 及可信代理。

健康、接口文档、注册和登录可匿名访问，其余业务及 `/metrics` 必须登录。旧 X-API-Key 或单独 X-Agent-Key 不能获得用户身份。共享路由在登录后还需要该账号库中的 Agent key 与空间 ACL；不同登录账号之间没有默认共享。
