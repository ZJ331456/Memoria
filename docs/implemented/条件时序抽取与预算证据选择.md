# 条件、时序抽取与预算证据选择

2026-10-12。本轮深化既有 Claim/双时间/统一访问，保留生产明确审核。工程回归 **463 passed / 116.86s**；新增31项算法反例及1项runner隔离反例，旧测试更新2项契约。执行墙钟不是开发工时、模型性能或长期效果。

## 1. 写入：有限槽位、可定位条件和变化建议

入口仍是 `POST /api/claims/extract`，一条本人用户消息、最多3条、整批事务、全部 pending。`infer_conditions`、`infer_time` 默认 false，需显式开启；普通 MemoryJobWorker 尚未自动接入 Claim。公开语料始终不能批准为账号本人事实。

| 模块 | 当前职责 |
| --- | --- |
| [claim_normalizer.py](../../memoria/memory/claim_normalizer.py) | 原12槽位校验；有限语言/详细度别名，NFKC/空白规范化；保留 raw_value，回答偏好的“希望用”与未来事件计划区分 |
| [condition_parser.py](../../memoria/memory/condition_parser.py) | 默认/面试/工作/学习/旅行/在家/办公室；逗号后继承、默认重置、句末结束；临时标志不推算到期日 |
| [temporal_resolver.py](../../memoria/memory/temporal_resolver.py) | 唯一明确 ISO 或中文年月日，UTC+8日历半开区间；仅同值语句中的日期可以绑定 |
| [evidence_verifier.py](../../memoria/memory/evidence_verifier.py) | SHA/span/来源角色/归属/撤销硬校验，加词面风险；可选 Supported/Contradicted/Insufficient 建议 |
| [update_policy.py](../../memoria/memory/update_policy.py) | 独立 Create/Reinforce/Transition/Review 影子策略，复用关系解析和原事务审批 |

例如“我平时喜欢用中文回答，不过面试模拟时希望用英文，而且回答尽量简洁。”的工程验收为：中文/default、英文/activity=interview、简洁/activity=interview。后一个分句可独立引用“回答尽量简洁”，同时把先前的“面试模拟”保存在 `condition_evidence` 的独立 SHA/span 中。该例使用测试替身验证程序边界，**不是本轮真实模型抽取成绩**。

模型漏 scope 时程序可以按原文补回；模型 scope 与原文/调用方同名条件矛盾、多个同值处于不同条件、复杂未知 if/only/unless 条件或无法唯一引用则422且整批不写。调用方额外条件可保留，但未在原话绑定的条件仍由核验器标 review，不视为模型语义已证明。

新增 `event_time={precision,lower,upper,quote}`。原话仅有“2026年10月搬到上海”则保存月份区间，`fact_start=null,time_precision=unknown`，不能推出10月1日已经住上海。明确日期可以使用 UTC+8 日边界，精确时刻必须有带时区的 ISO 引用。无日期/多个日期/非法日期/另一句的日期保留未知，既不从 recorded_at 推事件时间，也不让 LLM 任意生成时间字段。

条件引用参与支持来源索引、撤销和读取核验。修订强化不能改 event_time；关系比较也包含事件元数据。旧 JSON 没有新增字段时仍可读取，不重写生产历史。

来源片段正确和事实语义正确是两层。passing、Supported、人工批准都不等于独立现实核验；`semantic_support_verified=false` 保留。模型支持度输入新增条件引文/事件精度，不能解除主体、否定、计划、条件或日期的确定性风险；高风险和一般候选都不自动批准。精度不足时不会建议可执行 transition。

## 2. 查询：自然语言的双时间区间

[TemporalQueryParser](../../memoria/memory/temporal_query.py) 是规则基线，输出 `temporal_intent`、subject/predicate(s)、context、两轴 as_of（默认null）、两轴 interval、time_precision、requires_clarification 和原因。

| 查询 | 当前行为 |
| --- | --- |
| 我去年住在哪里 | `historical_fact`、去年的 `[lower,upper)`，展示有来源修订时间线，不声称整个年份成立 |
| 上个月的时候，你认为我住在哪里 | `historical_knowledge`、上月记录时间区间；区间前有效基线加区间内修订，屏蔽区间后新信息/未来退休时间 |
| 我什么时候从南京搬到上海的 | transition时间线，南京/上海是查询原文中的起终点约束；日/月/未知证据照实显示 |
| 我朋友住哪里 / 多个矛盾时间 / 默认和具体场景冲突 | clarify；实体需显式伪匿名ID，精确时间不能解除场景/身份冲突 |

年/月都不会变成伪精确 cutoff。时间线保留 pending/批准等状态并标 `historical_state_verified=false`，不把待审事实当过去知识；知识区间不走普通语义库补检，因为普通记忆没有记录时间轴。删除/撤销的当前来源也不会因历史查询恢复。

`use_query_model=true` 可明确开启 [query_router.py](../../memoria/memory/query_router.py) 的有限槽位建议：仅读取 query、原12槽位、唯一查询引用；不能输出值/时间/身份字段，不能删除规则槽位或解除规则歧义。默认0模型调用，启用后返回实际调用数/usage。模型分类建议仍未做真实路由准确率评测，规则保留为消融基线。

## 3. 统一访问与来源补检

[MemoryAccessOrchestrator](../../memoria/memory/access.py) 继续作为 `/api/memory-query` 和有限个人状态问法的入口：解析 → 已批准适用Claim/View → 不完整时生产RRF补检 → 来源/版本/时间复核 → 整组选择 → 返回路径与证据。

完整 View 不再额外检索；冲突/缺失 Claim 即使补检命中仍保持 clarify。原始源、引用和记忆提示分开，hint不作为已批准状态；公开数据、已撤销来源、源改写/记忆更新/失效区间均过滤。Claim从不无条件镜像到普通向量库。

历史区间返回来源有效的修订，而非将“区间相交”解释为确定某一天的状态；普通记忆的历史事件语义补检与通用实体解析仍待实现。API只读诊断不调用 reader；运行时把选中证据作为低信任输入，已有明确引用和拒答提示，但这一阶段尚无生产端严格引用ID输出解码；2026-10-13已接入有限严格通道，见[后续实现](完整Reader预算与生产引用校验.md)。研究 runner 对未展示引用ID直接计失败。

## 4. Evidence Selection：同池、整组、完整成本

新包 [evidence/](../../memoria/memory/evidence/README.md) 拆分 requirements/selector/budget/trace/reader_tokenizer；原 `select_evidence` 入口转调新实现。四种策略读取**相同 enriched 候选、需求、分数、预算和数量上限**：

| selector | 当前目标 |
| --- | --- |
| topk | 召回分数优先，整条超限则跳过 |
| coverage | 新增需求数优先，再按召回分数 |
| mmr | 0.5×归一相关性−0.5×最大词面冗余；中文bigram/英文词Jaccard，是词面MMR基线 |
| evidence_coverage | `(α×Rel + β×新增Coverage − γ×Redundancy)/max(1,边际成本)` 贪心，α=1/β=1/γ=0.35 |

Coverage来自查询/解析的槽位、条件、事实/记录轴、起终点和有限字面词；不读取 gold、可回答性、目标原话ID或人工标签。它是机械需求覆盖，不能证明语义充分性，因此 `semantic_sufficiency_verified=false`。同槽位Claim/条件/否定保持完整组；普通源按 source_id 去重，所有候选均保留 trace（排名值、边际成本、新覆盖、冗余、selected/budget/duplicate/top_k等）。参数未按gold调优。

`QueryRequest.selector` 新增 mmr/evidence_coverage，默认 coverage 暂不切换。`budget_unit=chars|utf8_bytes|reader_tokens`、`evidence_budget=256..16000`；省略时沿用 budget_chars。预算覆盖完整 evidence JSON，不包括 query/system/tools/输出；Claim候选生成本身仍有内部字符上限。字节预算不是远程Token实测。

reader_tokens 只允许服务器可信配置中 `local://` reader 的离线真实 tokenizer（不加载模型权重），或内部明确注入的可信计数器；HTTP/远程无可核验 tokenizer 返回422，禁止BGE替代/静默估算。这里只证明证据片段成本，不是完整提示窗口保证；本地生成后端原先对完整输入+输出窗口的核验继续独立执行。

## 5. Runner 与真实来源诊断

[runner.py](../../memoria/experiments/runner.py) 新增 `--evidence-selector` / `--evidence-budget-unit`，默认 legacy 保留原协议；新选择输出候选池SHA/完整候选/需求/trace。`qa` 可以使用新选择器，仍需明确远程授权，gold不进入reader/选择器。冻结64题不能通过limit削减失败分母。

[evidence_eval.py](../../memoria/experiments/evidence_eval.py) 可复用已捕获的 prefix-only 检索池，核验owner/manifest/artifact/source SHA/冻结输入/无未来原话，四策略各开不可覆盖新run。只允许原检索池，不再次选择已裁剪的池；原检索失败带入错误分母，score另读gold。时间参考固定为来源run起点。

```powershell
.\.venv\Scripts\python.exe scripts/research.py --user qin select-evidence --source-run 20261012T061426Z-e599965a --budget 1024 --unit chars
# 命令返回四个新run；逐个进行独立评分
.\.venv\Scripts\python.exe scripts/research.py --user qin score --run RUN_ID
# 新QA须单独登记预算/选择协议；远程执行还需 --allow-remote
.\.venv\Scripts\python.exe scripts/research.py --user qin run --mode qa --protocol lccc50-codex-dev-qa-20261012-v2 --baseline B2_rrf --evidence-selector evidence_coverage --context-chars 2048
```

本轮正式记录的是**来源选择诊断**，不运行新的QA、LLM抽取或远程路由。复用 `20261012T061426Z-e599965a` 的研究RRF（Dense+compact FTS两路，区别于生产三路加权RRF），50匿名公开对话/206消息/64开发QA，41可知/23不可知、AI辅助gold、0连续本人/0新批准Claim。三档预算×四策略=12run/768题次，64个独立问题被重复使用；零embedding/reader/其他模型调用，0错误，所有完整JSON成本≤预算。

| 预算字符 | Top-K：完整必要证据/41 | Coverage | 词面MMR | Evidence Coverage | 每策略空上下文/64 |
| --- | --- | --- | --- | --- | --- |
| 512 | 0/41 | 0/41 | 0/41 | 0/41 | 63/64 |
| 1024 | 20/41 | 20/41 | 20/41 | 20/41 | 0/64 |
| 2048 | 40/41 | 40/41 | 38/41 | 39/41 | 0/64 |

1024字符各策略 source recall macro 为51.22%，完整证据覆盖为48.78%；2048字符分别97.56%/97.56%/92.68%/95.12%。完整覆盖与宏召回口径分开。512字符几乎无法容纳保留来源与需求的完整条目，说明元数据成本不可忽略，不能只预算原文。

**结论：本批没有证明新选择器优于Top-K，2048预算还出现覆盖下降，因此不更改默认算法。** 不是新研究负结果被隐藏，也不从机械Coverage推导QA正确率。全部run ID、执行成本、候选一致性指纹、代码dirty指纹及cases/score SHA见[聚合记录](../../assets/evaluation/evidence-selection-20261012.json)。实验基于55ffd4c加记录中的工作区diff，未宣称当时已是干净提交。原始原话/gold/逐题输出保留账号私有目录，历史21轮成绩不覆盖。
