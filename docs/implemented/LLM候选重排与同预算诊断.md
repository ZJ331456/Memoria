# 可选LLM候选重排与固定预算诊断

2026-10-21第三项。**默认关闭，尚无稳定质量/成本收益证据。** 保留现有RRF；模型只提供候选顺序建议，不发布Claim、不补事实、不绕过主体/来源/条件/时间约束。

## 实现与使用

[rerank.py](../../memoria/memory/rerank.py)接收冻结候选，要求2–8项、完整输入不超过16000字符、最多一次1600-token输出调用。模型须返回全部原ID的唯一排列；direct/complementary须引用本项原话。跨来源拼接、伪造ID、重复、长度/工具输出、不确定项前移等均不能当成功，保留返回、usage和失败原因，回到原排序。整个池超限直接跳过，不截掉后半段凑成功。

`QueryRequest.use_llm_rerank=true`用于`POST /api/memory-answer`的普通来源回答；结构化Claim/时间线保持原权威路径，不能通过重排把原始经历当当前批准事实。`KnowledgeAnswer.use_llm_rerank=true`用于`POST /api/memory-kernel/knowledge-answer`的library原话阅读。普通`MemorySearch`不隐式调用模型；只有访问而未调用Reader时不执行该开关。当前Chat默认不开启，未增加配置文件。

普通来源重排后使用原选择器及原预算重选；底层Keyword/BM25/Dense/RRF分数仍保留在retrieval，模型排序优先级只作用于选择。资料保留原文、作者、版本、条件和位置，归纳表示不冒充原话。完整候选和原四种选择比较保留；`selection`是重排后结果，`reranking`单列模型建议/成本，`comparison`仍是原始基线，不能混看。

## 完整预算与追溯

额外模型请求前，按整个候选池构造完整Reader请求预留，包含系统提示、问题、引用ID、全部支持组、生成选项和输出空间。普通重排+Reader最多2次；同时启用`use_answer_risk`时预留两次充分性、一次Reader及两次支持核验，连同重排最多6次，合计输入字节不超过160000。预算不足就跳过重排；实际Reader/核验继续复核预算和新鲜度。远程模型无可信计数服务时是完整字节约束，**不是猜出的精确Token预算**；实际Token按提供方usage记录。

来源/别名在等待模型时撤回，会阻止发布。生产trace重新记录实际最终选择和水位；离线重放复用冻结模型建议，不再调用模型，不能把原RRF顺序冒充重排后的轨迹。资料读取的可见性记录替换为实际最终证据，并另存初始选择。诊断中的模型标签、引用一致性都不等于语义正确或现实核验。

## 四题配对协议

从仓库根执行，默认只验证、不调用：

```powershell
.\.venv\Scripts\python.exe scripts/evaluate_llm_rerank.py --user YOUR_USER
.\.venv\Scripts\python.exe scripts/evaluate_llm_rerank.py --user YOUR_USER --execute --allow-remote --max-calls 12 --budget-chars 3600 --direct-http
```

`--direct-http`仅在需要时按本机网络选择，保留TLS验证。运行只读取该账号的模型配置；所有来源/结果放在忽略的`simulation/runs/rerank-comparison-*`独立库，不读取/导入生产个人历史。

协议先固定官方LoCoMo校验和、第一段对话的QA索引0–3，四题选择不读取答案、证据或模型成绩。原文以外部资料录入，保留原speaker/session date/dia_id；原日期不冒充导入时间或事件时间。图像、caption、答案派生摘要不进入模型。采用当前**资料库词面候选**，每题冻结同一4候选、3600字符证据JSON及1400输出Token上限；两方法交替先后，标签等全部预测结束后才读取。不是个人RRF/Claim/Formation闭环评测，也不是旧PrefixRetriever全量成绩。

每题保存候选、依赖、请求、返回、usage、选中原ID、引用、Reader预算、共享检索及端到端时间，失败保留四题分母。Token F1沿用项目LoCoMo分类型词面计分；可见证据ID不保证片段充分，词面F1也不等于语义正确。相同字符/输出上限不等于相同实际输入Token。原始JSON/HTML与指纹留本机，不上传公开对话正文或私密配置。

初轮`rerank-comparison-c4085cce2375`，源排序/重排F1为8.17%/7.45%，总tokens为5617/11260，平均总延迟1149/2715ms；12调用、四题分母均保留。补强不确定项前移约束后，中间轮`rerank-comparison-4cb7d9233787`为5.36%/7.27%，5621/11378 tokens、1284/2781ms，重排3题应用/1题回退。它们是同一开发四题、不同核心版本，不能挑一轮或合并为独立重复实验，不能证明稳定质量提升；额外调用和延迟代价已经可见。最终同指纹结果另记。
