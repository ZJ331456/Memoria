写权限只由未被引用的直接命令授予；否定、回忆、询问及条件语句不因包含关键词获得权限。同一轮对同项能力同时出现允许与禁止时保守拒绝该能力，其他明确能力可保留。有限中英文规则不声称通用自然语言理解；歧义输入需要更明确指令。

## 2. Claim与情景工具的来源依赖

新增服务器内部ToolValue载体，依赖元数据在JSON与预算截断之前传递；不会从模型或MCP返回的JSON信任依赖。情景绑定原用户/助手消息快照，Claim绑定账号、完整访问请求与适用payload摘要；Reader前及发布前重验，Claim复核直接选择状态，不依赖旧缓存。使用这些证据的回答缓冲到校验及入库后才发送。通用自由文本仍不宣称语义引用契约完成。
