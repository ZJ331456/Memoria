## 对话与资料边界

Chat只展示本账号原生聊天；公开导入资料在Studio完整浏览。新对话按钮不写库，首次发送调用现有sessions创建和chat/stream接口，流式状态、回复和取消复用现有Agent。生成结束/出错/取消后重读实际保存内容；断流不自动重发。没有增加自由文本记忆自动批准或绕过Reader预算/引用校验。

Chat支持会话搜索和20条分页、每批50条历史/加载更早消息、移动端抽屉、输入法组合期间不触发Enter、助手Markdown与用户纯文本安全显示；暂不包含附件、语音或外部SSO。Studio移除聊天发送/新建逻辑，保留后台阅读和治理。

## 登录与隐私

shared/auth.ts和AuthPanel共用登录、注册、正式HttpOnly Cookie、换号与退出广播。广播只有变化信号；API分通道取消及epoch拒绝迟到响应，X-Memoria-User来自服务端实际鉴权身份，读取正文/流前核对。退出清空双方业务状态和在途流，SSE每次读块/派发事件重验epoch，不能把旧账号流接入新账号。服务器UUID仍是权限边界，超管不自动读取他人原话。

## 账号改密与聊天阅读（2026-10-15）

Chat与Studio右上角共用PasswordPanel：输入当前密码、新密码及确认密码，成功后清空内存表单、当前页面业务状态，并广播退出信号；所有旧登录需重新认证。服务端验证、频率限制与事务边界见[自助改密](用户登录与数据隔离.md#当前账号自助修改密码2026-10-15)。该次交付不改变任何真实账号的现有密码。

Chat消息布局改为用户靠右、助手靠左；改进气泡宽度、段落间距、移动端与自动增高输入框。助手保存记录与流式文本共用MarkdownContent，支持标题、加粗、列表、引用、代码和表格；用户输入按原样文本显示。每条消息可以复制原文，助手可切换“查看原文/阅读模式”。滚动离开底部后不强拉回最新消息，提供回底部按钮。Studio助手历史共用渲染器，可切回文本模式；搜索命中仍按文本投影高亮，来源面板和证据范围仍使用原文。

渲染采用固定依赖markdown-it与DOMPurify，关闭原始HTML并在输出端使用标签/属性白名单，不允许脚本、表单、内联样式或可执行URL。外链开启新页并带noopener/noreferrer；图片只显示占位说明，不自动请求远程资源。没有增加数学公式、Mermaid执行、代码执行或附件上传。引用标记仅显示，仍由后端校验是否有证据支持。参考[markdown-it安全说明](https://github.com/markdown-it/markdown-it/blob/master/docs/safety.md)、[DOMPurify说明](https://github.com/cure53/DOMPurify)。
