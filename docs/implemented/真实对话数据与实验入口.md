使用真实原文，不生成对话、用户名、日期或答案。下载校验镜像 LFS SHA256，子集保留 source_row 和 source ID，再记录 subset SHA。原始语料和数据库不提交，由脚本复现。

```powershell
.\.venv\Scripts\python.exe scripts/manage_users.py reserve qin
.\.venv\Scripts\python.exe scripts/prepare_real_dialogues.py --limit 50 --user qin
```

不传 --user 时仅下载公开子集；传 --user qin 时向该账号实际运行库事务导入会话/原话、消息 FTS 和数据库来源回执，不写 memories、不排后台抽取任务、不调用收费模型。重复导入检查全部原文并复用；原文被改写/删除则拒绝重新导入。迁移前独立语料 DB 归入 data/legacy/public-corpus。

## 能做与不能证明的事情

登录 qin 后可在 GET /api/sessions 查看对话，GET /api/datasets 与 /api/datasets/{dataset_id} 查看来源和消息映射。所有这些接口由当前登录账号选择数据库，其他账号无法读取 qin 数据。密码设置和目录见 [用户隔离](用户登录与数据隔离.md)。

可用于中文来源定位、表达噪声、抽取协议开发和人工标注的起点。导入保存原始顺序；原数据没有可核验说话者 ID，数据库消息暂使用 user 作为原话容器，**不表示每句来自同一个用户，也不建立画像**。

人物和事件时间为未知。不能把不同对话拼成一个人的长期历史，也不能据此报告变化适应或“越来越熟悉”的效果。尚未标注记忆事实、probe 和 gold，尚未运行正式长期陪伴实验。需要真实连续历史的收集与人工核验见 [计划的数据路线](../plans/长期陪伴记忆研究与实验计划书.md)。

本轮已删除原合成轨迹/模拟服务和旧合成基准入口。单元测试临时输入只检验工程机制，不导入用户库，也不冒充实验数据。
