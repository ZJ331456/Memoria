使用真实原文，不生成对话、用户名、日期或答案。下载校验镜像 LFS SHA256，子集保留 source_row 和 source ID，再记录 subset SHA。原始语料和数据库不提交，由脚本复现。

```powershell
.\.venv\Scripts\python.exe scripts/prepare_real_dialogues.py --limit 50 --import-corpus
```

该脚本仅向固定的独立公开语料库写会话/原话，不写个人 memories、不排后台抽取任务、不访问生产数据库或收费模型。重复导入核对 receipt 后复用；遇到无法确认的旧数据库拒绝覆盖。

## 能做与不能证明的事情

可用于中文来源定位、表达噪声、抽取协议开发和人工标注的起点。导入保存原始顺序；原数据没有可核验说话者 ID，数据库消息暂使用 user 作为原话容器，**不表示每句来自同一个用户，也不建立画像**。

人物和事件时间为未知。不能把不同对话拼成一个人的长期历史，也不能据此报告变化适应或“越来越熟悉”的效果。尚未标注记忆事实、probe 和 gold，尚未运行正式长期陪伴实验。需要真实连续历史的收集与人工核验见 [计划的数据路线](../plans/长期陪伴记忆研究与实验计划书.md)。

本轮已删除原合成轨迹/模拟服务和旧合成基准入口。单元测试临时输入只检验工程机制，不导入用户库，也不冒充实验数据。
