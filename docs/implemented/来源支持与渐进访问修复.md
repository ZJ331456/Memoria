2026-10-15开始，按[算法现状边界](算法现状与同类项目对照.md)和[下一阶段路线](../plans/下一阶段算法路线与对照实验.md)逐项实现。这里只记录生产机制和隔离工程验证；真实长期收益与语义抽取指标仍未知。

## 1. Claim 完整支持组

[claims.py](../../memoria/claims.py)现在使用组内 AND、组间 OR：一个组的主证据和条件证据全部有效，才能支持该 assertion；任一完整且已经批准的组存活，事实仍可使用。强化提交产生待审的新组，只有明确批准后才进入当前状态。主体、槽位、条件、极性、模态与事实/事件时间沿用原 assertion，强化不能修改它们；有 scope 的新组还须提交条件证据。

旧平铺 evidence 整体作为一个组读取，不拆成多份独立支持，也不重写不可变历史。支持组上限16；相同完整原文指纹及片段的复制不增加新 lineage，assistant 和公开导入原话仍被拒绝。此处只能识别精确复制，不能证明两段不同措辞是独立见证；语义支持仍由明确审核负责，`semantic_support_verified=False`。

撤回、删除、改写或改角色使涉及的整个组失效。公开读取只返回仍有效的组与引用；不能从不同残缺组拼出一个完整事实。原始组保留在不可变修订中用于本机审计，撤回优先于历史查询；事实级 retract/dispute 不因另一组存在而自动复活。View 编译器升级为 v4，来源 generation 与发布依赖复核使旧引用缓存失效。

`support_groups`包含真实支持组及其来源片段；历史字段`support_group_ids`保留为可用消息 ID 列表，不能把它当独立见证数量。普通记忆的强化/主来源依赖及关联普通父记忆的整体失效仍按原保守规则，不在本次 Claim 组间 OR 的完成范围内。

验证：`tests/test_claim_support_groups.py`及既有 Claim、演化、联动审核、算法管线、API、账号隔离和 Reader 契约共 **183项通过 / 58.16秒**。覆盖组内缺项、组间保留、待审接替禁止、审批前撤回、精确复制、旧格式、历史截止与缓存失效；输入均为系统临时目录工程用例，无模型调用。

## 2. 按来源版本与区间去重

[evidence/selector.py](../../memoria/memory/evidence/selector.py)的四种选择策略共用原文区间去重：来源ID+全文SHA确定同一版本；已选区间的并集完全覆盖新片段时丢弃重复，否则保留包含新原文的部分重叠或非重叠候选。缺坐标仍按来源ID保守去重；同一来源不同版本不得一起选。Claim/时间线仍作为不可切分的单元，条件证据也计入来源覆盖。

所有候选及决定继续留在trace，重复正文和元数据照实计入完整JSON预算，没有宣称共享元数据已压缩。覆盖特征和MMR仍为词面代理，引用合法仍不等于语义充分；这一步不自动产生生产多块候选。

验证：新增区间回归与既有算法管线、Reader、原文检索、审查回归共 **153项通过 / 36.77秒**。检查四策略的互补片段、并集覆盖、版本冲突、未知坐标、条件证据与完整预算；无真实模型或新质量成绩。

## 3. 原始经历的有界词面入口

[experience.py](../../memoria/memory/experience.py)在各账号SQLite中保存可重建的experience_versions/chunks/terms，原话写入和词面索引同事务提交；640字符块、96字符重叠，标题为前96字符原文，不使用模型摘要或QA gold。每块保留消息/会话、角色、记录时间、原文SHA与字符范围；事件时间明确unknown，不造人物ID或日期。

unified查询在状态不完整或无状态时默认补检经历，可用`include_experiences=false`消融。先BM25候选（至多16锚点），最多4锚点各展开同一原话的邻块，总邻块不超过8，随后进入现有四策略/完整预算。知识截止时间在语料统计、候选限制与邻块展开之前过滤；未来、assistant、撤回和公开导入消息不能作为本人经历证据。`fact_as_of`查询不使用缺事实有效区间的原始经历；现阶段自然语言日历区间仍走Claim时间线，不宣称一般事件时间推理。

新增经历候选不是已批准当前状态，不会把Claim缺项/冲突改成complete；完整View仍直接复用。Reader引用包含来源版本与span避免多块引用ID碰撞；生成前后重验原话、角色、会话、记录时间、公开来源归属和撤回，改写/删除后不发布旧引用。数据只在原账号库，不新增跨账号共享。

旧记录启动时最多回填32条，worker每批16条；持续有抽取任务也按间隔执行维护，不再必须等空闲。内容/角色/日期/会话修改原子删除旧索引，维护重建前宁缺不读旧版本。响应记录backlog_sources及实际锚点/邻块数，不把索引滞后当成没有真实资料。

这是词面BM25入口，尚无经历Dense/RRF、跨消息事件图、局部会话邻轮展开、索引SLO或真实质量结论；共享元数据暂按完整字节重复计量。新增14项经历回归；含Store/审核事务、一致性、Claim组、选择、Reader、API隔离等定向回归 **200项通过 / 50.67秒**。全部系统临时输入，无真实模型调用；完整工程回归另记。
