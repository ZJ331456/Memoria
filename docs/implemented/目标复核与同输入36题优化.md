# 目标复核与同输入36题优化

2026-10-24。根据用户提供的分析文档及上一轮私有逐题记录，本轮集中处理重复补检、删减后的时间答案不完整、来源参照日期被误当事件日期与过早预算阻断；所问对象漂移另做负向提示诊断。沿用v15的原36个问题、两段历史和独立机器Caption输入，最终仅完整Memoria一组；不追加四臂或1986题全量。[冻结登记](../../eval/protocols/kernel-memory-judge-v18-distinct-locators-36.json)。

## 先核对失败原因

上一轮15/28普通、6/8对抗，不能证明整体提高。26道可定位普通题的官方来源ID覆盖为初始14、补检15、Gate9、Reader8、引用8；来源ID只是可见性代理，不能作必要证据的语义标签。工程、模拟、BGE验收也不能代替质量收益。

本轮直接读取原始问题、Gate、Reader、两次支持返回与原文，零新增模型调用。这是AI辅助后验审计，不是独立真人标注，也没有把模型生成的标签称为人工Oracle。

- 一道时间题的初始原文和Gate均已绑定事件月份，但Reader改写成来源日期说明。支持检查否决该日期单元后，删除式修复只留下“本月”，独立支持仍误报答全。这是回答与完整性失败，不能归为没有检索到来源。
- 一道对抗题用另一种经营实体替代问题所问对象；原文支持相关经营状况，却没有建立两个实体名称等价。需要复核问题前提，不能靠真实引文自动放行。
- 另一道对抗题的原文明确描述近期负面经历，问题的宽泛用词存在可解释空间。保留原不可回答gold和原评分，单列可能的标注/语义边界争议，不能预设两次错误评分都证明来源不支持。
- 唯一未评分普通题在第二次Gate前被保守未来请求预留阻断，已实际使用输入约29KB，不能当成语料没有答案。

另对两个审计出的明确原话，使用v15只读向量快照及实际本地BGE做零远程调用的三路排名诊断。一个分类属性问题在词面通道约350名、Dense65，改成问题导出的绘画风格短语后Dense15；另一感受问题原Keyword10/BM2522/Dense29，缩短后Dense31或37。该结果包含负向，说明短查询不保证有效；不是完整形成融合复现、不是答案评分或人工必要组标签。全部细节仅本机留存。

文档建议的四臂与付费Oracle未执行。用户已明确最终只要一个框架组，本轮采用与v15相同输入的完整复测，减少Caption开关这个混杂因素；形成审核仍每次重执行，模型输出也会波动，因此不宣称单个组件的纯因果贡献或未见泛化。

## 集中修改

[query_plan.py](../../memoria/memory/evidence/query_plan.py)保留第一条带原问题的定位查询；只有一个缺项时，利用原有第二个名额生成不同的短定位词。优先采用与该需求有词项关联、不同于第一条的第二个补检建议（保留仅在该建议中出现的编号），没有建议时只去除有限疑问/语法外壳，保留主体、对象、否定、条件、数字和日期。两个缺项仍分别占一个名额。至多一次、两查询不变，原请求账号、会话、主体、条件和时间过滤不被定位词改写；短查询及模型建议都不能成为证据。

[adaptive_retrieval.py](../../memoria/memory/adaptive_retrieval.py)的第二次Gate显式收到上一轮缺失需求及本地binding阻断原因。原来值定位不是逐字引用时，模型可能在两轮重复同样错误，现在可以针对具体缺环重新检查。所有冻结需求、原话引文、完整依赖、撤回和独立支持要求继续执行。

内部v16增加了问题所指实体等价要求，加入后普通题为11/28，出现额外拒答和技术失败，未取得端到端收益；最终撤回这段宽泛提示，保留原主体、条件、原话及独立支持边界。不能把更严格的提示本身当作语义验证能力。所问属性/实体的可靠匹配仍待必要证据标签及独立校准，没有新增一个付费核验模型或置信度阈值。

Reader需把有原话和同来源时钟支持的相对时间，按原精度写成可独立理解的日历答案。对于冻结的时间需求，支持检查额外阻止仅剩“本月/去年”等无答案内日历锚点的字面单元。这同样适用于删减后的第二次支持核验，不能以引用里还保留时间戳冒充答案答全。没有新增事件日期、提高时间精度或允许补造主体关系。

[answer_dates.py](../../memoria/memory/answer_dates.py)修复首轮新复现的误拒：答案中的“相对来源日期……，也就是……”同时包含来源年份与推导后的事件年份，旧检查将两者一起当事件值，误报精度升级与年份矛盾。最终仅对有限英文参照解释语法，且解释中的日期确实匹配已引同来源完整clock时，从事件精度/算术检查中隔离该参照日期。原答案字面覆盖、完整clock引文及事件原话仍全部核验；错误来源日期、错误推导年份和没有该语法限定的混杂日期均不豁免。并非通用时间语言解析器。

预算仍为每题8次远程调用、累计240000 UTF-8输入字节、8000字符证据包。覆盖检查前预留完整Reader和两次支持检查；Reader格式重生成改为实际格式/长度失败时，才在剩余共享预算中原子预留。放不下完整重生成及支持就停止，不先花调用或隐藏重试。删减式修复仍只允许一次保留完整受支持单元，尚未接入Reader缺答后的新补检路径。
