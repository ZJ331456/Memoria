## 1. 生命周期水位与固定候选重放

[观测模块](../../memoria/observability/memory_trace.py)在账号SQLite安装事务内事件/epoch触发器，覆盖原话/撤销/公开导入、抽取任务、审核、普通记忆/操作/有效区间、来源依赖、向量/经历索引、Claim修订与View。事件仅记录阶段、表、实体ID、操作与观测时间，不复制原话；事务回滚一起回滚，无变化UPDATE不增加事件，重启不补造旧事件。水位从安装起算，不是全生命周期历史，既有LLM调用/usage仍由原trace账本记录。

统一访问返回production_trace：请求、账号、水位前后、候选/状态/要求/选择指纹及query-only覆盖特征；完整候选仍只在现有响应出现一次。Chat将轻量观测摘要加入本账号trace。changed_stages可见异步读取期间的变化，View自身物化也会记入，不能把它简单等同错误；输出仍以原来的来源/状态依赖复核为准。

[离线工具](../../memoria/experiments/production_replay.py)只读备份账号数据库为冻结输入，再在系统临时副本上执行同一访问代码；迁移/回填/视图写入不改冻结文件或生产库。默认lexical_only，显式--local-embeddings才使用账号配置的离线BGE；不允许远程Embedding、查询模型或Reader调用。副本水位和冻结来源均可核对；这不是重新运行旧抽取模型，未知的历史抽取输入/版本不能由元数据重建。

```powershell
# private-query.json为QueryRequest对象，只含问题和访问参数，不含gold或凭据
.\.venv\Scripts\python.exe scripts/research.py --user YOUR_USER capture-production --request .\data\private-query.json
# 可选离线BGE，不调用DeepSeek
.\.venv\Scripts\python.exe scripts/research.py --user YOUR_USER capture-production --request .\data\private-query.json --local-embeddings
# --input替换为上一步账号私有run下的production-capture.json
.\.venv\Scripts\python.exe scripts/research.py --user YOUR_USER replay-production --input CAPTURE_PATH --budgets 1000 2000 4000
```

replay-production校验账号与指纹，用同一捕获候选、query-only要求、Top-K和每档完整证据JSON预算比较四选择器，0模型调用。不能把字符/字节当远程Token；没有原可信tokenizer的reader_tokens重放拒绝。哈希检测意外改写，不是对抗本地篡改的签名；离线旧来源只用于诊断，不重新作为在线证据批准。

attribute是后验诊断接口：无标签返回unlabelled；只有显式提供必需来源ID时才区分来源不可用、状态未批准/不适用、未召回、候选未呈现、Reader未运行/契约失败/拒答与回答未评分。标签不进入检索或选择；ID覆盖不证明文本充分，真实语义正确性仍unknown。没有自动读取QA gold、生成评分或声称完整写入模型重放。

私密快照、候选原文和重放结果只在账号experiments目录；Git不收录。原trace已有脱敏不等于个人信息匿名化，本机管理员CLI和文件保留策略仍须按[账号边界](用户登录与数据隔离.md)与研究计划处理。商用长期留存/事件压缩尚未验收。

工程验收：新增11项重放/归因回归，与Claim、Reader、API及运行时共 **126项通过 / 49.64秒**。覆盖事务回滚、重启、冻结输入不变、跨账号/篡改拒绝、预算重放和在途水位变化；全部系统临时工程输入，0模型调用，不是研究质量成绩。
