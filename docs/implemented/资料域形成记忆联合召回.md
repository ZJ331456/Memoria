# 资料域形成记忆联合召回

2026-10-23。本次修复“形成后未参与回答”的生产路径，接在[资料域混合检索](资料域混合检索与多跳证据链.md)和[形成分组](形成分组与回答链路归因.md)之后。改动不是专用评测检索器，不读取答案、gold或未来来源；质量、成本及最终同指纹验收由本轮实际账本另行登记。

## 形成结果到原文

`SourceRetrieval`在原Keyword/BM25/Dense之外增加两个有界排序通道：已批准Observation描述的BM25排序，以及仍有效巩固记忆的完整支持原文回溯。每个通道对同一原文片段只投一次RRF票，权重均为0.9、常数60；重复观察不会无限增加同段票数。原模式继续控制原文通道，形成通道由`include_formed_memory`单独控制。原文最多扫描2000段/160万字符，观察至多2000条/160万描述字符；超限有明确诊断，不新增远程Embedding或LLM请求。

Observation检索使用已批准描述、主题、主体和条件，命中后返回原版本实际原文片段，含主体证据所在片段；不把生成描述改成原文。范围、会话、active/current head、最新反馈和独立审核先过滤；Embedding等待后再复核仍有效。有效巩固另保留独立`consolidated_memory`候选，必要支持组保持整体选择，原文回溯不代表事件、身份或因果关系已经成立。

原文候选的`provenance.formed_memory`是查询间稳定的组织提示。每段最多4个观察、总计最多1200字符；摘要与适用范围整条保留，超大条目仅保留观察ID和明确的`summary_omitted`回执，不截断否定或条件。这样不会因为一个长摘要让短原文整体无法进入Reader。摘要存在不等于命中所问属性、进入Reader不等于最终采用、引用带摘要的原文也不等于摘要被语义引用。

原文依赖增加`formation_refs`，绑定Observation/Card ID以及描述、适用范围、分组的结构化SHA。发布前继续复核原文版本、SHA、会话、反馈和审核有效性；仅撤销摘要审核而未撤回原资料，也会使已捕获的摘要依赖失效。原文仍可在下一次查询以其实际文字独立召回。

## 完整组与预算

巩固Reader表示去掉重复文件定位包装，保留全组原话、引用、每条适用范围、主体证据、反馈和结果；`source_id/revision_id/start/end`是追踪及原文定位的消费契约，继续逐项保留。主体原话已逐字包含于主quote时可去重并显式标记；否则保留独立主体原话及citation。带归属的支持继续提供真实source unit ID、speaker和原始日期声明，不把多条支持的日期冒充同一个事件日期。

默认8000字符完整来源证据预算、必要组不可截断、一次两查询补检和独立回答支持核验继续执行。组织摘要只作为提示，不进入`text`/`session_date_raw`的允许逐字引用字段；最终答案仍须获得原文支持。多来源日期问题仍需各自原文事实及日期锚，不能借摘要或上传时间补造。

## 消融与诊断

`MemorySearch`和`KnowledgeAnswer`新增`include_formed_memory: bool = true`。设为false同时关闭两个形成召回通道、独立巩固候选、knowledge cards、观察metadata、组织摘要及其依赖；仍保留原文、原始来源时钟、归属和既有身份保护。显式要求仅观察审核才能证明的事件/主体过滤时，无观察通道可安全拒绝，不能退回猜测。

`retrieval.library`区分`matched_observations`、`observation_hint_passages`、`consolidation_hint_passages`与`valid_consolidations`；完整有界lane列表保留原文citation。这些是召回提示计数。实际Reader摘要可见性须检查最终包的`formed_memory.observations[].summary`；仅ID回执不能计为摘要。明确巩固采用须检查`representation=consolidated_memory`及最终引用，不能把存储头数或提示命中当回答收益。

## 工程检查与边界

新增隔离合成测试覆盖：词面缺失时由批准描述召回真实原文、摘要不能冒充引文、关闭开关后的同库纯原文、工作会话隔离、撤回/修订/撤审、Embedding等待期间撤审、查询间稳定候选、超大摘要保留短原文、完整巩固主体与归属定位、结构化SHA字段边界及畸形依赖。均为工程契约，不能作为真实抽取F1或长期效果。

首次整套模拟48/49暴露了巩固压缩移除`source_id`后的真实追踪异常：Reader已返回，但Kernel生成answer trace时失败。修复为保留上述四项消费契约，并新增非Adaptive真实Kernel.answer引用巩固、生成完整来源lineage/trace的回归测试。保留失败账本，不能把这次失败当作通过；修复后的完整验收另行重新执行。

观察描述目前使用词面BM25，未新增形成记忆的独立Dense索引；原文Dense继续由实际本地BGE负责。检索通道、主题标签和摘要只是有界组织机制，是否提高36题或其他未见输入的回答质量，应以独立评分、失败分母、实际Reader参与和全生命周期成本报告。
