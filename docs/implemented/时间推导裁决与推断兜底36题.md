# 时间推导裁决、推断兜底与36题四机制复测

2026-10-24。基于全量1986题与原36题逐题私有记录的失败归因（961/1540普通题拒答是主分瓶颈、其中482/484为Gate整体判缺失、补检398题0新增候选），用户批准按P0→P3实施四项机制并逐轮付费复测原36题：时间需求定向推导裁决、必要引用补齐、Dense第二探针与召回上限16、以及仅限推断型问题的背景知识兜底。冻结登记 [v19](https://github.com/ZJ331456/Memoria/blob/38648d3/eval/protocols/kernel-memory-judge-v19-derivation-fallback-36.json)，输入、36个ID与Judge提示不变。

## 机制

- [derivation_review.py](../../memoria/memory/evidence/derivation_review.py)：第二轮Gate仍把时间类冻结需求判缺失时，从当前池收集同源"事件原话+会话时钟"对（每题至多1次调用、6对），由聚焦提示裁决是否按 as-of 语义以 basis=derived 绑定；输出经与Gate同一套逐字引文契约校验（同ID、完整时钟、字段白名单）后合并进冻结决策并整体重走 validate_plan。任何契约失败保持原缺失判定，只可能把拒答转为作答。
- [knowledge_fallback.py](../../memoria/memory/knowledge_fallback.py)：最终拒答点（含空候选池与"Gate充分但Reader自身拒答"）上，仅当问题本身含显式推断词（would/could/might等，query_risk判定）时，允许一次有界兜底调用：结合池内证据与常识给出带对冲的实质结论，标记 basis=inference、无引用、不写记忆、不走支持核验；返回裸拒答短语、超长、JSON回显或预算不足均保持原拒答。对抗题（具体事实型）不含推断词，不经过此路径。
- [adaptive_retrieval.py](../../memoria/memory/adaptive_retrieval.py)：Reader引用是已核验必要引用子集时自动补齐并原样复验发布，不再整题丢弃（未见过的引用ID仍硬失败）；补检第二探针改走Dense单通道（空召回显式退化回融合通道）；评估臂召回 limit 12→16。
- [evidence_sufficiency.py](../../memoria/memory/evidence_sufficiency.py)与[answer_dates.py](../../memoria/memory/answer_dates.py)：as-of 豁免两处对称落地——Gate侧 derived+同ID完整时钟的绑定不再因事件原话无时间词触发 event_time_not_bound/精度护栏；支持侧同条件下允许按时钟精度回答，但日时钟只降级为月精度（"recently+时钟"仍不得推出确切日，事件原话自带周/月精度仍不可被时钟锐化）。年份算术错配与逐字校验全部保留。

## 开发中暴露并修复的缺陷

第一轮复测17/28后，真实运行暴露三个实现缺陷，均先由工程手段定位再修复：Gate新增提示句的平铺措辞使真实模型把value/basis放到需求顶层（模拟48/49抓到，改为显式binding对象示例）；clock_pairs返回推导式引用循环残留变量，六对时钟全被赋成最后一条证据的时钟（单证据单测不可见，补多时钟回归测试）；兜底返回裸拒答短语被判无实质内容（judge对照），改为要求给出对冲结论。三次修复各自完整重跑工程、模拟与BGE后才进入下一轮付费复测，中间指纹与失败全部保留本机。

## 复测结果与波动

同一v19冻结输入共五轮付费复测（机制逐轮启用/修复，指纹分别为缺陷版→`9eeef1ba…`→`6d3d28af…`→终态`8b8e26e3…`）：17（时钟缺陷版）、19、19、18、17（终态）。逐轮调用233/235/236/244/234次，单轮高峰上界$0.411–0.422。终态两轮中，18/28一轮含1次支持契约波动、1次judge解析失败与既有标注争议对抗题；17/28一轮含1次支持契约波动，多跳类Gate判定跌至2/8。

轮间±2以上波动主要来自Gate判定、独立支持核验与Judge解析的模型非确定性；四机制本身无逆向下沉（19/28两轮中19-20次作答、错答0-2次，作答精度90–100%，与全量96.8%的资产一致）。对照v18（15/28、1题未评分）：最好两轮配对14对皆对、8对皆错、4升1降、1未知；单跳7→8、开放域1→3、时序轮间4–5、多跳2–4波动、对抗保持8/8（下降项均为v18已记录的"近期挫折"标注争议对抗题与judge解析失败，非机制回归）。

按真实优先于分数原则，[公开聚合与指纹](../../assets/evaluation/evidence-flow36.json)导出终态代码完整轮（17/28、1题执行失败保留分母）；中间指纹的19/28两轮及全部失败保留本机私有目录，逐题原文、提示词与SQLite不变。36题上与完整历史Baseline（≥21/28）的差距约2–4题，当前机制未稳定跨越。
