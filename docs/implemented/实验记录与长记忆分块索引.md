## 长记忆写入与检索

`EmbeddingClient.embed_documents` 使用本地 BGE tokenizer 切分原文连续字符 span，每块最多 512 token，含 special token，覆盖全文且不通过 decode 改写原文。HTTP BGE 客户端需本项目 tokenizer，服务端应使用相同权重/编码策略；任意远程供应商暂没有通用分块协议。

父记忆保留完整正文与版本。`memory_embedding_chunks` 保存模型 namespace、序号、span、token 数、原文 SHA 与独立向量。归一化块均值仅是父粗向量；Dense 检索按最佳块相似度给父记忆评分再融合，不把多块当多个事实，也不让同一父记忆占满结果。SQLite KNN 逐步扩大块候选，JSON 回退受父候选扫描上限约束。

父版本、区间、父向量与块在同一事务落库；更正关闭旧版本当前索引，撤销恢复旧块，删除级联清理，历史查询按父版本区间读取历史块。延迟回填先核对父正文和活动状态，避免并发更正后写回旧索引。

返回正文仍完整，`retrieval.chunk` 标记命中位置，多块记录提供 `retrieval_excerpt`；PromptAssembler 和 recall 优先使用片段。完整编码不代表完整正文进入最终 prompt，也不保证问句通过当前相似度门槛。

旧父记忆已有粗向量但缺完整当前空间块索引时仍会待回填。显式接口：`POST /api/memories/reindex?limit=1000`。目前有批量上限和读路径回填成本；后台游标、蓝绿迁移和大库覆盖审计仍待实现。服务/tokenizer 失败或 query 超限仍可能真实降级为词面检索。

## 实验账本

`RunRecorder` 保存代码 SHA/dirty 指纹、输入/模型/tokenizer 文件 SHA、环境硬件、参数、运行状态与产物 SHA；`ExperimentLLM` 按 reader/extractor/decider/judge 保存实际 prompt、原始返回、finish、usage、重试、错误、墙钟与可见文本 TTFT。

模型版本未知时保留未知；本地文件 SHA 提供定位。没有调用的角色不补造成本，合法空抽取不是执行异常，质量须另由真实标注核验。运行产物在 `data/`，不提交私人对话或凭据。真实 runner 已实现，操作与边界见 [真实历史标注与评测](真实历史标注与评测.md)；抽取开发诊断已实际运行，AI 辅助开发 v2 冻结 64 题（41 可知/23 不可知），真实 QA 调用未执行。正式变化/陪伴实验等独立真人 gold 与真实连续资料。

2026-10-12 标注冻结会话墙钟 543.602099 秒包含原话阅读、来源工具和复核，不能算真人工时；校验 50 分组/206 消息全覆盖、32 陈述 span/SHA、64 题前缀与输入/gold 分离，生产仍 0 memories。完整工程回归 298 passed / 64.14 s，随后评分来源字段补验 37 passed / 21.16 s；两个 AI/同人版本不能满足正式 test 双人条件。

## 阶段耗时

`metadata.stage_timings` 覆盖压缩、planner、检索/候选/回填、query embedding、块候选、融合、prompt 组装/预算、reader 与工具等实际执行阶段。`StageTimings` 隔离每次请求，失败与取消保留 failed 计数。

时间含客户端/HTTP、调度和推理等待，嵌套阶段不可相加。TTFT 从 reader 请求到首段非空可见文本，排除 reasoning/tool delta；非流式为 null，不是 GPU 第一采样 token。当前没有增量视图，所以没有 view-check 阶段成绩。
