# 本机后台启动与停止

2026-10-14。入口为根目录[start_backend.cmd](../../start_backend.cmd)，内部执行[scripts/backend.ps1](../../scripts/backend.ps1)。支持Windows PowerShell 5.1，无需管理员权限；始终使用项目`.venv/Scripts/python.exe`，保留私密配置和账号模型覆盖。

## 使用

先按[根README](../../README.md#首次准备环境)准备环境、`config.toml`和Studio构建；以后双击`start_backend.cmd`即可隐藏启动业务API。关闭启动窗口不停止后台进程，也不需要保持虚拟环境激活。

```powershell
# 仓库根目录
.\start_backend.cmd
.\start_backend.cmd -Action Status
.\start_backend.cmd -Action Stop
# 可选：独立端口或已有配置；配置路径含空格时加引号
.\start_backend.cmd -Port 2238 -Config "configs/my-local.toml"
```

默认监听`127.0.0.1:2237`，Studio为`http://127.0.0.1:2237/studio/`，API为`/docs`，存活检查为`/api/health`。登录仍走正式账号网关，不生成默认密码。配置文件不存在时明确失败，不退回示例配置或覆盖现有配置。

## 进程与日志

- 使用`Start-Process -WindowStyle Hidden`，绝对路径和独立参数引号支持含空格的项目路径。
- 日志在忽略目录`data/logs/system/backend-端口-时间.{out,err}.log`；进程记录在`data/run/backend-端口.json`，不提交Git。只在本机排查，勿公开包含业务信息的日志。
- 本机命令互斥锁避免同时双击启动/停止引起竞争；重复启动同一已管理且健康的进程直接返回。其他进程占用端口时拒绝另起服务，不接管或杀掉该进程。
- 停止前核验PID、创建时刻、原命令行、项目入口和端口，防止PID复用误杀；Windows venv转发产生的子Python仅在父进程及命令行一致时一同停止。属于本机进程停止工具，商业优雅停机和多实例协调尚待验收。
- 启动默认等待最多30秒（`-TimeoutSeconds 1..60`）；失败/超时给出日志路径，保留进程以便`Status`/`Stop`，不循环重启或自动安装依赖。

脚本只启动业务API。若选用本地HTTP Qwen/BGE，还需先启动8080模型服务；进程内BGE/远程LLM使用已有配置。不会自动下载模型、改base环境、重新构建Studio或运行benchmark。Studio未构建时API可启动并提示构建；构建后重启业务。
