# 本机后台启动与停止

2026-10-14。启动入口为根目录[start_backend.cmd](../../start_backend.cmd)，关闭入口为[stop_backend.bat](../../stop_backend.bat)，内部执行[scripts/backend.ps1](../../scripts/backend.ps1)。支持Windows PowerShell 5.1，无需管理员权限；始终使用项目`.venv/Scripts/python.exe`，保留私密配置和账号模型覆盖。

## 使用

先按[根README](../../README.md#首次准备环境)准备环境、`config.toml`和[Chat/Studio统一构建](../../frontend/README.md)（双击[build_frontend.cmd](../../build_frontend.cmd)）；以后双击`start_backend.cmd`即可隐藏启动业务API。关闭启动窗口不停止后台进程，也不需要保持虚拟环境激活。

```powershell
# 仓库根目录
.\start_backend.cmd
.\stop_backend.bat
.\start_backend.cmd -Action Status
.\start_backend.cmd -Action Stop
# 可选：独立端口或已有配置；配置路径含空格时加引号
.\start_backend.cmd -Port 2238 -Config "configs/my-local.toml"
```

默认监听`127.0.0.1:2237`，独立Chat为`http://127.0.0.1:2237/`，Studio为`http://127.0.0.1:2237/studio/`，API为`/docs`，存活检查为`/api/health`。登录仍走正式账号网关，不生成默认密码。配置文件不存在时明确失败，不退回示例配置或覆盖现有配置。

双击`stop_backend.bat`即可关闭该脚本管理的业务后台，不必打开终端。非默认端口用`.\stop_backend.bat -Port 2238`；服务未运行时可重复执行。成功后窗口自动关闭，失败时保留提示供查看。

## 进程与日志

- 使用`Start-Process -WindowStyle Hidden`，绝对路径和独立参数引号支持含空格的项目路径。
- 日志在忽略目录`data/logs/system/backend-端口-时间.{out,err}.log`；进程记录在`data/run/backend-端口.json`，不提交Git。只在本机排查，勿公开包含业务信息的日志。
- 本机命令互斥锁避免同时双击启动/停止引起竞争；重复启动同一已管理且健康的进程直接返回。其他进程占用端口时拒绝另起服务，不接管或杀掉该进程。
- 停止前核验PID、创建时刻、原命令行、项目入口和端口，防止PID复用误杀；再按已核验的根PID结束完整进程树，包含Windows venv转发、MCP桥接和服务子进程，不按Python/Node名称批量杀进程。独立启动的8080模型服务不在这棵树内，不随之关闭。属于本机进程停止工具，商业优雅停机和多实例协调尚待验收。
- 启动默认等待最多30秒（`-TimeoutSeconds 1..60`）；失败/超时给出日志路径，保留进程以便`Status`/`Stop`，不循环重启或自动安装依赖。

脚本只启动业务API。若选用本地HTTP Qwen/BGE，还需先启动8080模型服务；进程内BGE/远程LLM使用已有配置。不会自动下载模型、改base环境、重新构建Studio或运行benchmark。启动脚本分别检查frontend/dist/chat/index.html和frontend/dist/studio/index.html；缺少时API可启动并提示构建，构建后重启业务。旧/app/已移除，单个后端同时托管两套独立页面和共享/assets/。

已私密启用的[飞书机器人渠道](飞书机器人对话接入.md)也随业务启动，官方长连接在所属Python子进程，统一关闭会清理它；不另开公网端口。SDK仅安装到项目.venv。配置文件缺失时默认关闭，状态/绑定需登录Chat或Studio查看。
