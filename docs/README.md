## 评测与验证状态

- **原LoCoMo全量：** 10段长对话/5,882条原话/1,986题（1,540普通、446对抗），最终执行错误0。普通F1首次56.12%、复核后58.65%；对抗官方拒答短语分94.17%→92.38%。[首页分类表](../README.md#locomo-全量评测)与[完整说明](implemented/LoCoMo全量评测与英文检索修复.md)区分方法、预算和指标；不是语义准确率或真实长期效果。
- **P0完整消融：** 同1986题，定向57.47%普通F1/92.83%对抗/7290.80已知Token每题；风险自适应51.15%/95.96%/12663.62，最后0/1工程失败保留分母。综合目标未达、生产默认保持，[实现与校准](implemented/证据充分性与风险感知回答.md)记录全部费用、代理与契约限制。
- **历史LCCC开发评测：** 50段匿名短对话/206消息、64道AI辅助QA；固定21轮为768检索题次/576实际reader调用。字面匹配与LoCoMo官方F1不可直接比较，原失败、图表和指纹在[历史报告](implemented/DenseRRF自动评测与视图性能.md)及[资产目录](assets/evaluation/README.md)保留。Window/Dense/RRF是方法，不是三个数据集；20,000条下载归档未全量评估。
- **视图性能边界：** 真实账号副本0已批准Claim、5,400次空状态访问全为clarify；只测空缓存开销，正向画像视图收益与生产HTTP SLO未知。
- **工程验证：** 本轮v3与后台保护合并90 passed / 28.51s，另有隔离真实启动链通过；0新模型调用/0新评分。历史P0工程全量548 passed / 135.77s；历史TLS/续跑版本全量525 passed / 199.78s，后续失败恢复受影响24 passed / 11.42s。工程通过不转换为研究正确率；完整预算与有限引用ID校验不证明语义蕴含。已有前端构建/真实HTTP验收见[Studio说明](implemented/MemoryStudio与统一记忆访问.md)。
