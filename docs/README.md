## AI 读取与文档维护

根目录 [AGENTS.md](../AGENTS.md) 要求读取本页、对应模块说明，并在提交/推送前读取提交规范。Codex 支持自动发现 AGENTS.md，其他客户端需确认支持或显式读取；提交推送仍遵循用户授权，不通过隐藏钩子自动发布。

实现文档只记录当前行为与验证边界，未完成项写 plans。变更能力时同步导航、模块 README 和 API。真实记录注明来源、模型和失败分母；工程替身不作为用户数据或质量成绩。

每项工作完成时，同次变更更新 implemented 对应说明、计划的阶段状态/证据/下一步验收和本页导航，不能仅在聊天中宣布完成。密码、Secret 和 token 只记录配置状态，绝不记录值。当前 **P0 工具、公开抽取诊断与 AI 辅助开发标注冻结已完成**：50 段/206 原话覆盖，32 条陈述和 64 QA（41 可知/23 不可知）已冻结 v2；下一项是 B0/B2 实际开发 QA 和真人独立审核。连续人物历史、正式人工 gold、长期陪伴质量实验、Claim 和视图仍待开展。完整状态见 [研究计划](plans/长期陪伴记忆研究与实验计划书.md#当前进度与下一步)。
